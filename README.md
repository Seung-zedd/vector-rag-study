# Vector DB & RAG Study

Vector Database와 Retrieval-Augmented Generation(RAG)을 기초부터 이해하기 위한 재사용 가능한 학습 레포지토리입니다.

## 학습 원칙

각 레슨은 개념을 충분히 대화하고 이해한 뒤에만 문서화합니다.

목표는 API를 외우는 것이 아니라 다음을 할 수 있게 되는 것입니다.

- 개념을 설명한다.
- 실제 시스템을 관찰한다.
- 결과를 검증한다.
- 다른 프로젝트와 연결해서 재사용한다.
