# Vector DB & RAG Study

A reusable learning repository for understanding Vector Databases and Retrieval-Augmented Generation (RAG) from first principles.

## Study rule

Each lesson is materialized only after the concept has been discussed and understood.

The goal is not to memorize APIs. The goal is to be able to explain, inspect, validate, and reuse the concepts in future projects.

## Scope

This repository contains only generalized learning material and synthetic/public-safe examples.

It intentionally excludes:
- company-internal datasets
- proprietary API responses
- private system designs
- credentials or secrets
- project-specific confidential information
